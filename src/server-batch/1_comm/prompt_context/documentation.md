### Prompt context precomputation

Space-to-ground transcription quality improves dramatically when WhisperX is primed with day-specific mission context. The helper script `src/server-batch/1_comm/5_corpus_initial_prompt_ai_gen.py` automates that preprocessing pipeline.

Prerequisites:

- Ensure the `.env` file contains valid paths for `RAW_FOLDER`, `WEB_ASSETS_FOLDER`, `IA_ZIP_SG_FOLDER`, and `IA_ZIP_AG_FOLDER`.
- Populate `${WEB_ASSETS_FOLDER}` with `crew_arr_dep.json`, activity summaries, and blog article bundles (generated by the existing server batch scripts).
- Start the Ollama daemon locally (`OLLAMA_API_URL` defaults to `http://localhost:11434`).

Key features:

- Deterministic crew roster snapshots at 00:00:00Z and 23:59:59Z with handover notes when the crew changes mid-day.
- Daily brief extraction that flattens activity summaries, ingests blog articles, and caches map-reduce style GPT-OSS summaries per day.
- Prompt synthesis that constrains output to ≤250 characters, saves rich metadata and streamed JSONL traces, and respects static vocabulary overrides from `PROMPT_CONTEXT_STATIC_VOCAB`.
- Parallel execution with a Rich-powered `--monitor` view that streams partial Ollama tokens for each worker.

Example invocation:

```bash
python src/server-batch/1_comm/5_corpus_initial_prompt_ai_gen.py \
  --start-date 2024-01-01 --end-date 2024-01-07 \
  --workers 3 --monitor
```

The script writes outputs under `${RAW_FOLDER}/prompt_context/YYYY/MM/DD/`:

- `crew_roster.json`: crew snapshots
- `daily_brief.json`: activity + blog digest
- `prompt_input.json`: assembled context payload
- `prompt.txt`, `prompt_meta.json`, `prompt_raw.jsonl`: final prompt string, telemetry, and streamed Ollama frames
- `blog_cache/`: cached article summaries keyed by content hash

If a day has already been processed, rerun with `--force` to regenerate. Use `--discover-comm` to infer dates from the `comm_transcripts_aacs` tree or `--dry-run` to list the plan without executing.
